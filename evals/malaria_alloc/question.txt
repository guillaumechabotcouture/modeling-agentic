SYNTHETIC TEST QUESTION (evaluation suite): every district, number and file below is synthetic, generated for this test; none describes a real place. A malaria programme must choose one intervention package for each of 10 districts for 2026-2028, within a budget of US$17.0 million. Packages: none; ITN (one mass campaign of insecticide-treated nets); IRS (annual indoor residual spraying); ITN+IRS; SMC (seasonal malaria chemoprevention, only in districts marked SMC-eligible); ITN+SMC; ITN+IRS+SMC. The nets from the 2022 campaign have expired, so the counterfactual for 2026-2028 is no ITN, IRS or SMC anywhere. Input files: data/evals/malaria_alloc/districts.csv (population and SMC eligibility), data/evals/malaria_alloc/programme_history.csv (recorded clinical cases by district and year, 2015-2024, under the package each district had that year; assume complete recording, stable populations and no trend other than the packages), data/evals/malaria_alloc/unit_costs.csv (cost per person covered over the whole plan). Because the setting is synthetic, estimate the effect of each package from the programme history; published effect sizes may be used as priors only. Choose the allocation that maximises clinical cases averted over 2026-2028 within the budget, report the total cases averted with a 95% uncertainty interval, and state the decision rule. Deliverables: allocation_optimized.csv in the run directory with columns district, package (exactly one of the package names above) and cases_averted; and the uncertainty analysis must report the total as an output named total_cases_averted.
