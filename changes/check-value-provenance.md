## Changelog

**Finding provenance: which findings led to an amendment, and whether it changed the decision.** `toolkit/spec/amend.py` gains `motivation(parent, request, declared, required)`: the child's `metadata.json` and `amendment_record.json` carry `motivated_by` (schema `motivated_by/1`), the parent run's id and, for each motivating finding in the parent's `findings.jsonl`, its id, kind, source, critic category (from the parent's critique YAMLs) and answer fingerprint (`findings_ledger.answer_fingerprint`). It is required for a rethink-driven amendment (`--from-request`, lead and owner paths: the request's findings and its briefs' findings), so a request naming none is refused with no child; a manual patch may add `motivated_by: {findings: [ids], reason}` (each id must be in the parent's ledger; a declaration naming none needs a reason), else the record says `source: unstated`. The spec, its sign-off, the sheet, `patch_sha256` and `parent_run` are unchanged. A relaunch with `MA_PARENT_RUN` records `motivated_by` from the parent's rethink request (`stage_machine._relaunch_motivation`). `scripts/harness_metrics.py` gains `provenance`, `compare` (plan, headline beyond 0.5%, decision-test verdicts, child against parent, from `analysis/point.yaml`, `estimates.yaml`, `decision_tests.yaml`) and a per-finding-kind amendment table; `--check-value <run dirs>` prints it with the per-check productive / noise table of the check-value analysis (runs, rows and HIGH, executed fix tasks once per check and their dollars, owner items by the owner, resolution codes, productive in a run by the impact rows and the spec's allocation file, amended and changed, wording and re-raise noise, class), from the existing records only; copies with the same ledger bytes count once under every name. A child no longer copies the parent's `impact_ledger.jsonl`. Not computed: blocking gate-rounds, allocated loop dollars, and findings shown false by a later commit. Self-tests AM_MOTIVE_FROM_REQUEST, AM_MOTIVE_UNSTATED, AM_MOTIVE_REQUIRED, AM_MOTIVE_DECLARED, AM_MOTIVE_REFUSED, RR5b, RR6, HM43-HM52 (Codex round 1); the lead-amendment fixture now names its motivating finding.
