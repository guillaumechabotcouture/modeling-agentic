## Changelog

**v2 autonomy 1B-i: the engine choice keeps a signed configuration, considers only a named engine, and pays for no pick when one engine is eligible.** Items 2.a to 2.d of `docs/design/v2-autonomy-brief.md` PR 1B, as the re-audit found them open. Configuration: for a spec that names its engine with a configuration (`engine: {ref, config}`), `analysis_backend.eligible_engines` uses that configuration as written (`named_engine`); before, the engine's own function of the spec replaced it, so the card checked and the configuration recorded in `engine_choice.json` were not the ones the schema builds the engine from (a non-default mode was dropped, and an engine configured from an estimates spec could not be named in another spec). A check on a signed configuration that must hold before the engine is built stays in force (`SIGNED_CONFIG_CHECKS`: the package-rate component limit). A named engine with no configuration is configured as before. Candidates: `candidate_entries` returns the named engine alone for a spec that names one (the schema reads a named engine from the spec, never from the choice); `engine: auto` keeps the registry or the signed candidates, and an explicit `engines` list is considered as given. The spike adapter's `choice_spec` keeps a signed `auto` after a choice, so a back-edge still considers every engine. Pick: `sole_pick` gives the choice when exactly one candidate is eligible, and `SdkTasks.pick_engine` returns it with no session and no cost (`_no_session_when_sole`); a pick that carries the reasons of a rethink still runs. `engine_choice.json` gains `pick: {eligible, task}` with `task` `skipped_single_eligible` or `ran`. Prompt: the `draft_spec` prompt says when to write `engine: auto` and when to name the engine with its configuration; `spec_forms` finds, by calling each registered engine's configuration function, which form configures it, and the self-tests hold the prompt to that. Not in this PR: the shortcut is in the task layer, not in `h_ENGINE_CHOICE` (`agents/stage_machine.py` is unchanged), so the journal still records a `pick_engine` entry, at no cost; the evidence stage (1B-ii) and the benchmark items (1B-iii). Self-tests B_EXPLICIT_CONFIG, B_EXPLICIT_EMPIRICAL, B_EXPLICIT_EMPIRICAL_MAX, B_EXPLICIT_NONE, B_EXPLICIT_RENEWAL_ALLOC, B_NAMED_ONLY to B_NAMED_ONLY6, B_SINGLE_NO_LLM, B_SINGLE_NO_LLM2, B_SPEC_FORMS, S_SINGLE_NO_LLM, S_SINGLE_NO_LLM2, S_ENGINE_FORMS, S_ENGINE_FORMS2.
