## Changelog

**The harness stamps each critic's reviewer and id prefix; the spec drafter hears the staged paths and the statements rule; a delivered report is not counted as withheld.** Baseline hb2 triage fixes 6 to 8. Critics (§4.5: three runs each lost one schema repair to the presentation critic writing reviewer `presentation` or `critique_presentation`, or ids `R-NNN`): `agents/v2_sdk_tasks.py` `stamp_critique`, run after every critique session, and only when the session wrote its file, writes the literal reviewer and gives each blocker id `X-NNN` with another prefix the critic's (`validate_critique_yaml.PREFIXES`), its `carried_forward` references with it. The new number is the first, from the one written, that no blocker in the file and no earlier round uses (frozen tests, the findings ledger, the file the session replaced), so a new finding never takes an old finding's id or test; when those records cannot be read nothing is renumbered.
