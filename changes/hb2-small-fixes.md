## Changelog

**The harness stamps each critic's reviewer and id prefix; the spec drafter hears the staged paths and the statements rule; a delivered report is not counted as withheld.** Baseline hb2 triage fixes 6 to 8. Critics (§4.5: three runs each lost one schema repair to the presentation critic writing reviewer `presentation` or `critique_presentation`, or ids `R-NNN`): `agents/v2_sdk_tasks.py` `stamp_critique`, run after every critique session, writes the literal reviewer and turns each `X-NNN` id with another prefix into the critic's (`validate_critique_yaml.PREFIXES`), in `blockers` and `carried_forward` alike. An id whose stamped form is already in the file is left as written for the gate to refuse (two findings are never merged), and a file that is missing, unreadable or not a mapping is left as it is (the gate refuses it). The critique prompt also states both literal values. Spec draft (§4.6): the no-digits rule in the draft prompt and the decision-spec skill names the yes, no and undetermined texts of `deliverable.decision.statements` (two runs retried on it); the draft task's message lists the staged input paths from `data/inputs_provenance.json`; when a cited path does not exist, or is not derived or staged, but names a staged input (by its repository path, or by a file name only one staged input has), both refusals name the staged copy (`pipeline.staged_copy_hint`, used by `record_cited_inputs` and `derivation_problems`); each SPEC retry's history entry keeps the try's whole feedback under `feedback` (the `why` line stays cut at 200 characters). Report (§5 fix 8): `scripts/harness_metrics.py` counts a run that ends with a regular `report.md` and a completing status as done, noting a stale `report_withheld.md` beside it (every withhold path moves `report.md` away, so the one left is the delivered one; the retro-check on one hb2 run changes its done column from N to Y); and `Machine._go` to FINAL removes that leftover once `report.md` is delivered (`_retire_stale_withheld`; the repair stays in the history and the gate records). Self-tests CS1-CS4, SD1-SD2, T50f, SH1, T84b, HM2b (each failed before its change).
