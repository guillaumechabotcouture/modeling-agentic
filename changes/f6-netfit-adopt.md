## Changelog

**The uncertainty draws can read the net-effect fit's verified joint sample (opt-in).** A signed spec that sets `uncertainty.net_effect_posterior: <path>` (the file `net_effect_fit.py run` writes, `net_effect_fit.yaml`) has every uncertainty draw take one whole row of the fit's accepted joint sample, `joint_region.sample`, for the sample's parameters. Rows are chosen on their own random stream (`uncertainty.NE_STREAM`) after the priors and fitted ranges are drawn, so a parameter without a sample (the PBO parameters, which the fit leaves out) is drawn from its prior exactly as before, and the correlation between the fitted parameters is kept. One loader, `net_effect_fit.load_posterior`, reads the file. It refuses (fails closed) when the file is missing, unreadable or not the script's output, when it comes from a smoke run, or when the acceptance gate did not pass (`sample_status` not `verified`, a reason left in `acceptance`, a failed verified point). It also refuses when the engine name or code differs from the engine in use, when the sample is empty or a row lacks a fitted parameter or holds a non-numeric or non-finite value, when a column is not a parameter these draws vary (an engine-card prior from `priors.yaml` or a spec prior, or a fitted parameter under the `engine_parameters` source, and not calibrated), and when a value lies outside its draw range. The run binds the file into the manifest: `engine.net_effect_posterior_sha256` and an input of the engine artifact. The uncertainty report records the sample's path, sha256, names and the row each draw took, and refuses a file that changed while the draws read it. Without the field nothing changes: the same draws, the same manifest, no engine code touched (the engine fingerprint and the benchmark stamps are unchanged). `run()` and the self-tests' placeholder now write the file through one function (`document`). Self-tests F14-F15 (`net_effect_fit.py`, 17 refusal cases, each checked for its own reason) and NP1-NP4 (`uncertainty.py`, NP1 against the draws recorded before the change) were written first and failed before the change. They use a placeholder sample in the script's own format, because the real fit is still running. No cloud run.
