## Changelog

**The uncertainty draws can read the net-effect fit's verified joint sample (opt-in).** A signed spec that sets `uncertainty.net_effect_posterior: {path, sha256}` has every uncertainty draw take one whole row of the fit's accepted joint sample, `joint_region.sample`, for the sample's parameters. The path is the file `net_effect_fit.py run` writes, `net_effect_fit.yaml`, and the owner signs the sha256 of its bytes. Rows are chosen on their own random stream (`uncertainty.NE_STREAM`) after the priors and fitted ranges are drawn. A parameter without a sample (the PBO parameters, which the fit leaves out) is therefore drawn from its prior exactly as before, and the correlation between the fitted parameters is kept. The file is read once per spec (`uncertainty.posterior_input`, through `net_effect_fit.read_signed`), and bytes whose sha256 is not the signed one are refused. The same bytes feed the manifest's `engine.net_effect_posterior_sha256`, the engine artifact's input (a `(path, sha256)` input in `artifacts.Store.write`, not re-read) and the draws. One loader, `net_effect_fit.load_posterior`, reads the bytes. It refuses (fails closed) when the file is unreadable, malformed or not the script's output, or when it comes from a smoke run. It refuses when the engine name or code differs from the engine in use, or when the sample is empty or a row lacks a fitted parameter or holds a non-numeric or non-finite value. It replays the fit's own acceptance gate, `finalize()`, on the file's evidence (the verified points, which must be rows of the sample; the chosen point; the calibration grid's edge record) and refuses unless it passes, whatever the summary fields say. It refuses a column that is not a parameter these draws vary (an engine-card prior from `priors.yaml` or a spec prior, or a fitted parameter under the `engine_parameters` source, and not calibrated). It refuses a value outside its `priors.yaml` card range, whatever wider range a spec prior declares, or outside its draw range. The uncertainty report records the sample's path, signed sha256, names and the row each draw took. Without the field nothing changes: the same draws, the same manifest, and no engine code touched, so the engine fingerprint and the benchmark stamps are unchanged. `run()` and the self-tests' placeholder write the file through one function (`document`). Self-tests F14-F15 (`net_effect_fit.py`, 22 refusal cases, each checked for its own reason) and NP1-NP4 (`uncertainty.py`; NP1 is checked against the draws recorded before the change) were written first and failed before the change: α for the feature, γ for Codex review round 1. Round 1 found two P1 and two P2 findings: an edited row was accepted; summary fields were trusted over the gate's evidence; a spec prior wider than the card range bypassed `priors.yaml`; the manifest hash was read separately from the bytes used. The reviewer's probes are cases in F15 and NP3, and all eight failed against the pre-fix loader. The cases use a placeholder sample in the script's own format, because the real fit is still running. No cloud run.
