## Changelog

**Reuse key narrowed to what a row depends on.** A stored batch row's reuse key (`scripts/compute.py` `code_fingerprint`) is now a hash of recorded parts instead of every file under `scripts/` and `toolkit/`: the job's inputs (the row key, unchanged); `extra`, the engine identity `toolkit/analysis/batch.py` passes (`contract.engine_identity`); `closure`, the repo code the batch function can reach, found statically by the new `scripts/lib/import_closure.py` (the function, every top-level definition its code names through its module or an import, the import-time code and data files of each module reached, compute.py's row path from `FP_ROW_ROOTS` with `FP_DISPATCH_EXEMPT` not followed); `run_files`, the run's `models/` and `data/` as before; `deps`, the dependency manifests. Each batch summary and partial journal records `key_parts` and the closure (files with their sha256). The walk fails closed: an unresolvable repo import, a dynamic import in reached code of a file without an `FP_DYNAMIC_IMPORTS` declaration, a star import of a module that re-exports what it imports, a guard loader with no class check (`import_guard.FP_LOADERS`: `attr`, `module`, `resolve` outside kind `engine`), a dynamic import in run code (run code cannot declare its own), or an unparsable file adds the whole-tree hash to the key and records the reasons (`closure_unresolved`); the fallback also hashes the run's own Python files outside `models/` and `data/` (`run_code`). `toolkit/import_guard.py` declares what each import kind can load (`{kind: paths}`, taken at call sites with a literal kind; IG-FP checks each policy is inside its paths). Files are hashed by content at every size: no mtime. A batch stored before this change is still reused while the old whole-tree key matches (`_legacy_fingerprint`, byte-identical to the old key), and is restamped. `compute.py reuse-check` names the part that differs. Self-tests FP_CLOSURE_RECORDED, FP_CLOSURE_UNRELATED_EDIT, FP_CLOSURE_ENGINE_EDIT, FP_CLOSURE_CARD_EDIT, FP_ENGINE_IDENTITY, FP_INPUT_EDIT, FP_RUN_DATA_EDIT, FP_REUSE_CHECK_PARTS, FP_UNRESOLVED_IMPORT_FALLS_BACK, FP_UNRESOLVED_NO_REUSE, FP_LARGE_FILE_CONTENT, FP_OLD_ROWS_STILL_REUSED; import_closure IC1-IC7.
