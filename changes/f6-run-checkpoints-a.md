## Changelog

**Run checkpoints on the agent VM, fetch and resume from them, and a final checkpoint before the watch stops a launch (F6).** On 2026-11-11 the F6 preview ran 3 h and was stopped at its spend cap by `cloud/launch_watch.py`. A v2 run stores its run directory only when `main.py` ends, so nothing was stored and 3 h of engine batches were lost. (1) While `main.py` runs, `cloud/worker_side.py` `Checkpointer` uploads a tarball of the run dir every `checkpoint_minutes` (new `RunConfig` field, default 15, 0 off) to `outputs/<storage_prefix>/launch_<id>/checkpoint_<label>.tar.gz`, then its record `checkpoint_<label>.json` (time, size, sha256, run state and round, cached engine batches and rows). The tarball (`runs/<RUN>/...` and `run.log`) is built by the new `scripts/results_store.py` `write_archive` with the final store's exclusions (no `_truth/`, no credential files, API keys redacted); `upload_file` streams it and verifies the read-back. One upload runs at a time, a checkpoint due while one uploads is skipped, and a failure is logged and never stops the run. (2) `run_cluster.py <cfg> checkpoint [--label L]` downloads the latest checkpoint and refuses on a sha256 mismatch; `collect` says when a label has only a checkpoint; `checkpoint-now` asks the running thread for one checkpoint, bounded. (3) Resume steps are in the `run_cluster.py` module doc ("Checkpoints"); a run dir restored from a checkpoint reuses its finished engine batches and its interrupted batch's journal (`scripts/compute.py` reuse path). Known limit: a file over 64 MB under `models/` or `data/` is fingerprinted by size and mtime, which tar does not keep, so it makes every batch recompute (`reuse-check` shows it). (4) `launch_watch.py` runs `checkpoint-now` once, bounded, before the stops at its spend cap and at `--max-hours`; a failure never delays the stop, and the exit message names the checkpoint. Self-tests written first: CK1-CK12b (`run_cluster.py`), LW19a-LW19d (`launch_watch.py`), CP0-CP3 (`compute.py`), S8-S9 (`results_store.py`). The dollar cap measured from Coiled's bill, the checkpoint requirement and the signed-budget check follow in a separate PR.
