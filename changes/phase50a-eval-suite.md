## Changelog

**Eval suite: planted-truth questions with deterministic graders (workstream F1); the hidden half is encrypted outside the public repository.** Each harness change is to be measured by four numbers per run: answer quality against a known-good answer, rounds, dollars and wall time. Until now we had single runs of about US$500 on one question, and the planted-defect test checks the gates, not the answer. Five small questions on synthetic data. Each has a public question text (`evals/<q>/question.txt`), synthetic inputs in `data/evals/<q>/` (shipped) and a launcher config (`cloud/configs/eval_<q>.py`: US$35 cap, 3 rounds, lead sign-off, `EVAL_TAG` / `EVAL_TREE` / `EVAL_REPS`). New `scripts/eval_suite.py` (disease-agnostic): `run` (preflight, prints the launch commands; launches only with `--execute`; eval runs execute only on the cloud, and `--local` refuses), `grade <q> <run_dir>` / `grade --root`, `report A [B]`. Grading extracts a JSON answer from the run's artifacts, then scores rubric checks over a subtask DAG, with a gated score, false-confidence penalties and a failure taxonomy (`evals/taxonomy.yaml`) that names the most upstream failing layer. **The hidden half is not in the repository.** The repository is public, so each question's seeded generator, rubric and answer key, the question-specific tests and the design note form one tarball. It is encrypted with Fernet (`cryptography`, now pinned; it was already in the venv) and stored as ciphertext in the IDM Coiled storage account, at `outputs/evals_private/v<N>/bundle.enc`, with a manifest of the ciphertext's sha256 and each question's input hashes. New `scripts/eval_private.py` reuses `scripts/results_store.py` (account from `$COILED_STORAGE_ACCOUNT`, DefaultAzureCredential). The key is held only in the maintainer's macOS login keychain, since run VMs can read that storage account and agents have a shell. `evals/private.yaml` pins the version and the ciphertext hash. `grade`, `run` and `generate --check` decrypt into a temporary directory that is deleted afterwards. Any failure (no pin, no account, missing blob, hash mismatch, wrong key, unsafe archive member) refuses with the INFRA finding `answer_key_unavailable`, not a crash or a score. Maintainer commands on the laptop: `fetch <dir>`, `generate --private-dir <dir>`, `publish --private-dir <dir> [--new-key]` (uploads, checks that a download and decrypt work, then writes the pin). The grader picks the answer key whose input hashes match the run's: the launch record's hashes, or with `--unverified-inputs` the run's own input copies. A legacy key (`legacy/malaria_alloc_20261030`) keeps the completed blind run v2blind1 B1 gradable. **Regenerated:** every question has a new seed and new planted values within plausible ranges, and five question texts were updated to match (budgets, dose blocks, populations). The version 1 generators, rubrics and design note stay in git history. The record of what changed is in the encrypted design note, not here. **Kept from the first review rounds:** `.gitattributes` export-ignores `evals/`; `code_tarball` refuses a tarball holding hidden paths or `.git`; an eval question runs only on an isolated cloud worker (`MA_EVAL_ISOLATED`, checked on the effective question including `--resume`); allocations are checked for feasibility before any credit; replicates and input hashes come from the launch record; the shipped-text leak scan covers keywords and truth numbers. **Tests:** S1-S14 (engine; S12 no hidden file under `evals/` or tracked, S13 answer key chosen by input hashes including legacy, S14 `grade` without the bundle refuses with a finding), E1-E6 (`eval_private`: pack, encrypt, upload, download, decrypt and grade give the same scores; a wrong or malformed key, a missing bundle or manifest, a pin or ciphertext hash mismatch, an unsafe member and a missing storage account all fail closed; the temporary directory is deleted), the bundle's question tests Q0-Q4, C1-C2, L1-L7 and R1-R11 (`--self-test --with-private`), EP1-EP11, RC50. **Retro:** v2blind1 B1 graded on the new path picks the legacy key from the run's own input copies and scores quality 1.00 with 7/7 checks, the same per-check scores as the old path. **Codex round 3 (seven P1s, each test first):** `fetch`, `publish` and any `--private-dir` refuse a directory inside any git checkout, symlinks resolved (S17); check details and scores.json no longer state a hidden target or its relative width (S15); SIGTERM or SIGHUP while the bundle is open still deletes the decrypted directory (E9); differing copies of one input in an unverified run, or copies that match no key, are refused (S16); every manifest field must agree with the pin and the ciphertext before decryption, and a malformed manifest is a finding (E7); a hidden tree missing a generator, rubric or key is refused before publish and when opened, and a missing file is `bundle_incomplete`, not a crash (S18); upload failures are `storage_error` (E8).
