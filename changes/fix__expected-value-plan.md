## Changelog

**Expected-value plan as a spec option (hb1 triage fix 11, cause J).** A spec may now write `deliverable.plan: expected_value`. The analysis then delivers the plan with the best mean benefit over the uncertainty draws, within the budget in every draw, instead of the plan solved at the point values. It is the same solve as the value-of-information step's `robust` candidate: both call `toolkit/analysis/plan_rule.py mean_plan`, and both leave out the packages a point-value model correction bears on. The draws are evaluated once and the uncertainty step reuses them. The allocation file then carries each unit's mean over those draws. The claims add `headline.mean` (the fixed plan's mean over the draws, on the signed headline outcome) and `plan_rule.units_differ`, and results.md names the rule. `point.yaml` records `plan_rule`: the point-value plan and its solve, the units that differ, and the plan's cost at the point costs, flagged when over the budget. Stability, sensitivity and the decision tests still re-solve at the point values. The decision-tests artifact therefore names `reference_plan: point_plan`, and the owner finding for a plan-changing test says so. Several things refuse or stop. A model correction on the comparator or a whole unit blocks the run with `analysis/blocked.yaml`. The budget frontier is not drawn, and an earlier run's frontier files are removed; any figure not drawn now loses its earlier files. A rebuild from the point tables is refused. The completion gate checks the plan rule against the signed spec, including the per-unit means and the reference plan. The schema refuses an unknown value. It also refuses `expected_value` without an uncertainty source, with `uncertainty.affordability.enforce`, with `analysis.plan_variants`, on an `estimates` deliverable and with `by_group`, and an estimates spec refuses the key altogether. A spec without the key gives the same plan, allocation file, uncertainty files and claims as before, and no engine job hash changes. The decision-spec skill names the option. Self-tests: SPEV1-5 (schema), PR1-11 (plan_rule), EV-R1-10 (run).
