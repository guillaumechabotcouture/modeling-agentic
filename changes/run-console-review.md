## Changelog

**Run console review fixes (Codex review of #124).** Each finding reproduced by a failing self-test first (RV1-RV17, RS1-RS5, SG11-SG12, T70). Artifacts are treated as untrusted: the page script is a separate file under a CSP with no inline script, every attribute value is escaped or a JS-side ref, served artifacts are sandboxed; every artifact read goes through one confined reader (no absolute path, `..`, credential file or link out of the run dir) and every console write opens its directories and file with no-follow. Decisions are bound to the run and the content shown: an HMAC ticket per decision card, a request sequence on the page, `agents/stage_machine.py sign --expect-sha256` (toolkit `signoff.sign` hashes and records the same bytes), scope answers keyed by the fingerprints shown; remote answers name their run (`cloud/run_cluster.py sign --label --run --expect-spec-sha256`; `worker_side.sign_side` refuses another newest run and signs a v2 spec through `stage_machine.py sign`). A mirror is classified by path containment; its sync status is shown and a stale mirror cannot be approved remotely. Chat reserves each message's worst case under the lock (input tokens from `count_tokens`, else UTF-8 bytes; Opus 5.5 plus fallback rates), keeps the reservation when usage is unknown, and serializes one run's turns. Decision tests have four states (changed, unchanged, not run, error). Feedback carries an evidence snapshot; anchored chat carries the excerpt; citations are checked against what was sent; lineage says "related run (inferred)" unless the spec shas are equal and diffs `objective.outcome` and the decision tests' values. The console moves to `tools/run_console/`, outside `compute.code_fingerprint`'s directories, so editing it no longer invalidates stored engine batches; `scripts/self_tests.py` discovers `tools/`. Round 2 (Codex on #129): engine references are an allowlist checked before any import (a spec naming `subprocess:Popen` ran it on load); the sign commands read the spec once and write no-follow and atomically (`lib.safe_io.read_nofollow`/`write_nofollow`); the console reads through no-follow fds and its own read model, never the harness loaders; `derived_changed` refuses outputs outside the run dir; the spec approval is one snapshot (sheet, spec and derivation-record sha256) checked by `stage_machine.py sign`; remote signing takes an explicit `--action`; an interrupted chat stream keeps its reservation; evidence is captured at render; relations stay "(inferred)".
