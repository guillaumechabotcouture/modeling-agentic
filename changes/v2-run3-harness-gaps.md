## Changelog

**Four v2 machine gaps F6 run 3 exposed (it ended budget_exhausted).** (1) Write-up findings (owner state WRITE or PRESENTATION) are no longer FIX_LOOP tasks, which may edit only analysis_settings.yaml and models/ext/ and so could never pass their checks: `agents/fix_loop.py` moves them out of the planner's packet (`write_up`), refuses a task naming one, and the machine passes them, with their remedies, to the writer (`write(..., findings=)`); a loop left with only write-up findings and a draft goes to WRITE. (2) A SPEC rethink of a signed spec drafts its proposal in `<run_dir>.spec_proposal.<k>/` beside the run dir (one per SPEC visit, never removed) (lib.safe_io refuses a write root inside a run dir), a copy of the spec's inputs and cited files laid out as a run dir, so every pre-sign check runs on it while the signed files stay untouched; SIGN waits for the owner (never the lead) to sign the proposal there (`stage_machine.py sign <run_dir>.spec_proposal.<k> --by owner`), then copies the earlier spec and its sign-off records to `spec_history/<j>/`, puts the proposal's spec files in their place and keeps a copy of the proposal in `spec_history/<j>/proposal/` (every write through lib.safe_io). A proposal that went missing (a copied run dir) sends SIGN back to SPEC (new edge SIGN -> SPEC), never on with the old spec. (3) A finding whose `fix_requires` names an owner amendment is not planned (no SPEC rethink): the loop's summary lists it (`owner_amendments`), the machine writes `scope_signoff_request.json` in scripts/scope_signoff.py's format and goes to OWNER_DECISION (new edge FIX_LOOP -> OWNER_DECISION); the critique prompt asks critics to start such a remedy with "Owner amendment:". The ledger now reads the fingerprint-keyed answers `scope_signoff.py sign` writes. (4) A paid task whose allowance is below `MIN_TASK_ALLOWANCE_USD` ($0.50) is not started: the run pauses `paused:awaiting_budget` (exit 2), and `main.py --v2 --resume <run> --max-budget-usd <higher>` raises the cap (recorded in the history) and continues.
