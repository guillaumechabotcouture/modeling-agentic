## Changelog

**Add the agent-built engine admission gate, oracle library, calibration wrapper, built coverage policy, try tool, compute reservation, and Coiled production bundling (PR gamma of `#363`).**

- `toolkit/engines/built/thresholds.yaml` and `toolkit/engines/built/oracles.py`: harness-owned admission thresholds and the 12-function test oracle library matching `requested.KNOWN_ORACLES` (re-exporting existing closed forms plus SIS endemic prevalence, constant-rate stable age distribution, constant-hazard survival, and multigroup SEIR ODE). Self-test `OR1`–`OR7`.
- `toolkit/engines/built/candidate.py` and `toolkit/engines/built/worker.py`: add harness-only `CandidateEngine` (blocked by `import_guard` for all policies) executing unadmitted snapshots through the same minimal-mount bubblewrap worker and reporting identical `code_fingerprint`/`identity_extra`/`ENGINE_REF` as `BuiltEngine`; extend `worker.py` `BalanceAnalyzer` with module lookup, element-wise minimum tracking, and `max_rel_drift`, plus `has_batch`/`run_batch_state` support for A3.
- `toolkit/engines/built/calibrators.py`: add `calibrate_as_run` dispatching through the run's calibration path (`mode_start.fit_posterior_panel`, `calibration.fit_likelihood`, `calibration.invert`, `joint_calibration.run`) with `scripts/identifiability.py` Fisher/profile-likelihood ridge detection. Self-test `BE16`.
- `toolkit/engines/benchmark_coverage.py`: add `policy="built"` (auto-selected for `BuiltEngine`), refusing `effects_from_spec`, disabling `posterior_trained` exemption, and accepting only `in_band` unless covered by a signed departure. Self-test `BE15`.
- `toolkit/engines/built/admission.py` and `toolkit/engines/built/fixtures.py`: implement typed public/hidden/real-unit generators, checks `A1`–`A11` (conformance, cross-process/`PYTHONHASHSEED`/order/opaque-ID determinism, batch-vs-run parity, oracle reductions + derived identities, closed mass balance + compartment transition-count witnesses, sensitivity wiring + `param_reads`, non-vacuous directions, built-policy trials + authoritative `bench/*`, literature benchmarks, A10 identifiability, deterministic & stochastic equivalence A11 with `inconclusive`), overfit detection (`engine_overfit_suspected`), hidden-seed commitment, reuse key + `try_reuse_admission`, and `admission_sheet.md`/atomic `admission.json`. Self-test `BE1`–`BE11`, `BE13`, `BE15`, `BE17`, `BE32`, `BE33`.
- `toolkit/engines/built/try_tool.py`: implement `engine_try` and `engine_run_one` with persistent 30-call ledger (`engine_build/try/ledger.json`), domain validation, public-only checks, and 8 KB summary cap. Self-test `TRY1`–`TRY2`.
- `agents/run_budget.py` and `scripts/compute.py`: add `reserve_compute`/`reconcile_compute` against the run's remaining balance before dispatch (`BE33`), and extend `make_bundle` + `_run_files_digest` to ship/fingerprint ONLY the production subset of `engine_build/` (`admission.json`, `signoff.json`, `request.json`, signed snapshot, `bench/`) while excluding `.hidden/`, `reference/`, `try/`, `hidden_reveal.json`, and `models/ext/engine_*` (`BE34`).
