## Changelog

**Critique checklist: five structural checks, two computed by the harness.** Owner decision 2026-11-23, from an outside benchmark in which frontier agents' models stopped at "good": comparator asymmetry, holdout windows over shock periods, burn-in drift, rankings driven by under-reporting, and reduced-form natural history that sidesteps a known tension. They are principles 8-12 of `.claude/orchestration/decision_design_principles.md`. New `toolkit/spec/critique_checklist.py` holds the items, the schema and the two deterministic checks. `comparator_symmetry` compares the components across the spec's packages: an arm lacks a background component (one the comparator holds and another arm holds, or, with an empty comparator, one every other arm holds) and no arm is that arm with the component added. `holdout_shock_overlap` runs when the spec declares the new optional `periods: {holdout, shocks}` section. Both are pre-sign checks in `toolkit/spec/spec_critique.py` (MEDIUM, declarable in `principle_departures`; a malformed `periods` section is HIGH). The domain and red-team critique files carry `checklist: {item: {answer: pass | finding | not_applicable, reason, blockers}}` for every item the harness did not answer. `validate_critique(..., checklist=<harness answers>)`, called so by `v2_gate` in any run (its run_state.json or spec exists), refuses a missing or unknown item, an unknown answer, a blank reason, and a finding that names no open blocker of the file, as schema errors (the legacy gate passes none). A finding is an existing blocker, so the checklist adds no finding, and pass or not_applicable costs no round. The harness answers an item itself only for a computed pass or not_applicable, or a finding the spec declares; an undeclared computed finding stays the critics' to answer. The critique system prompt lists the items, and the review message gives the computed results as JSON data (`v2_sdk_tasks.checklist_text`); the spec is read with no link followed. `StubTasks` answers them. The gate record holds `critique_checklist`. Self-tests CL1-CL27, SC41-SC46, CK1-CK6, SCK1-SCK3, SM-CK1-SM-CK5, CL8a-CL8c, CL14a, CL15a-CL15b, CL25a (Codex r1). The harness id stamp (`stamp_critique`) renames the checklist's blocker references with the ids.
