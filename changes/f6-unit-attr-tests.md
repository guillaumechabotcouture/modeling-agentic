## Changelog

**A decision test can vary a unit attribute: a units-table column that feeds an engine unit attribute.** New type `unit_attribute` (`toolkit/analysis/decision_tests.py`): `unit_attribute: {column, units: [ids] | all, values: [..] | scale: [..] | set_from: <table in the run directory>}`. Each case is a copy of the table `Spec.units()` read, evaluated and solved by its own analysis (`arm_analysis`), built from that table by the headline's constructors: alloc spec, population-share caps, feasibility, the headline variant (`variants.apply_headline`) and the model's per-unit state. The headline analysis is never modified. `Spec.packages` prunes over every arm's table too, so the headline and every arm share one package set. The calibration is redone on the emulator-inversion path and held at the headline values otherwise, and the record says which. One planner (`plan_unit_attribute`) is used both at sign-off (`schema.validate`) and at run time. It refuses an unknown column, a column bound to no engine attribute or only to the calibrated one, unit ids not in the table, a value mode other than exactly one of values, scale or set_from, a set_from table outside the run directory, a case outside the attribute's declared domain (`EngineCard.valid_ranges`; an attribute without one is refused), on the emulator path a column that reaches no emulator feature or leaves the design box, and a test whose every case leaves the built inputs (engine attributes, or encoded emulator features) unchanged. Sign-off reads the same emulator design box as the pre-run plan. A set_from table is read once, and `Store.write` accepts `(path, sha256)` so the bytes executed are the bytes bound. The record (`models/decision_tests/<id>.yaml` key `unit_attribute`) names the column, attributes, units changed per case and the sha256 of each modified table and of the base table. A set_from table is a hashed input of `analysis/decision_tests.yaml`. This closes the decision-test half of the unit-attribute uncertainty gap in `docs/design/v2-progressive-steps.md` §6.7. Drawing unit attributes in the uncertainty draws is still open. Self-tests SP-UA1-11 (`toolkit/spec/schema.py`), UA1-16 and UA-R1-R4, UA-R6 (`toolkit/analysis/run.py`; the review probes of #228).
