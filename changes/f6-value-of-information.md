## Changelog

**Value of information from the uncertainty draws (owner, 2026-11-12).** The analysis step now says which uncertain input is worth better data, from the draws it already evaluates (no new engine runs; ILP solves on those tables only). A read-only `on_solve` hook in `UQ.run` hands each draw's sampled inputs, benefit and cost tables, re-optimised plan and model corrections to `toolkit/analysis/value_of_information.py`, which writes `analysis/value_of_information.yaml` (new artifact kind). Deciding now is the best plan within the allocatable budget in every draw (one solve with a budget row per draw beside the signed caps; with an overspend allowance, the best candidate within it, labelled a lower bound). Perfect information takes, in each draw, the best plan feasible there, overspending in no more draws than the plan chosen now may, so EVPI is never inflated by overspending. Candidates (the headline plan, plan variants, the plan decided now, each draw's optimum and the plan decided within each quantile bin of each input and group) that break the signed feasibility or carry a model correction in any draw are reported with their regret, never chosen. EVPPI per drawn input and group by the regression method of Strong, Oakley & Brennan 2014 (natural cubic spline, knots by GCV), with feasibility after learning judged within the input's bins, over the candidate set; each value carries a permutation noise floor computed with the full procedure (GCV repeated), no percentile interval, and is claimed only when supported (above its floor, not above EVPI). Below 30 draws the artifact records too_few_draws; below 500 values are indicative (thresholds.yaml `value_of_information`, proposals for the owner). Inputs not drawn are listed with why. Claims, a results.md section and a contract check (`analysis_contract_value_of_information`: the EVPI identity, signs, diagnostics, the chosen candidate, status consistency; fail closed); `enabled: false` turns it off with the uncertainty outputs unchanged. Self-tests VI1-13, VG1-7 and VR1-7, and review round 1's reproductions D1-D10 (two Codex reviews), written first, failed before each change.
