## Changelog

**An owner-signed cloud budget and its measured spend (F6 S2-BG1).** On 2026-11-11 an agent operating this repo spent $106 of the owner's $100 cloud budget. The budget, the dollar conversion and the spend checks lived in the agent's memory and judgment. New `cloud/budget.py` puts them in code. The budget is a signed record: scope, usd, start_utc, note, issued_utc, expires_utc, nonce, and the scope's cluster-name prefixes and projection floor, both copied from the tracked `cloud/budget_scopes.yaml`. It is signed with an Ed25519 key held in the macOS login keychain with an empty trusted-application list. `init-key` passes `add-generic-password -s modeling-agentic-budget-owner -a owner -l modeling-agentic-budget-owner-key -T "" -w <key>` to `security -i` on stdin, so the key never appears on a command line. Each signing read (`find-generic-password ... -w`) raises the keychain's password dialog, which an agent cannot answer. Records are verified against the tracked public key `cloud/budget_owner.pub`. These are refused: a missing or unparsable file, a bad signature, a changed field, an expired record (default 14 days, `set --days N`, at most 60), and a record issued before the newest one already seen for its scope. That last check reads `~/.config/modeling-agentic/budget_<scope>.seen`, a local high-water mark that makes replay harder but is not tamper-proof. Commands: `budget.py init-key` (once), `set --scope --usd --note [--start] [--days]`, `show` and `status` (budget, billed, projected and remaining, per cluster). Spend covers every cluster in the IDM workspace created since the budget's start whose name has one of the signed prefixes. Billed USD = `total_cost` (credits) x 0.061 + `cloud_total_cost`, from the raw cluster record (coiled 1.135.6 `CloudV2._get_cluster_details_synced`, `coiled/v2/core.py:976`; the public `cluster_details` drops the cost fields). A cluster not yet stopped counts max(billed, its instance-hours so far x the median USD per instance-hour of the scope's last five stopped clusters, never below the signed floor of $1.00), so a bill that grows while a cluster runs is not counted twice. `launch_budget_ok(scope, cap_usd, name=None)` is true only when three things hold: the record verifies, the name is in the signed prefixes, and spend + cap <= budget. Any error refuses. `job_meter(scope)` reads one cluster's USD. Self-tests BG1-BG16 (generated test keys, a fake key store, a fake keychain runner and a fake Coiled source) were written first and failed before each change.
