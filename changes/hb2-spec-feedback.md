## Changelog

**A SPEC try hears every problem, and a try lost to the turn cap no longer erases the feedback.** Baseline hb1: a SPEC retry happened in 9 of 10 runs. Four runs lost a try to the 30-turn cap, and `h_SPEC` then replaced `spec_feedback` with "draft_spec failed: max turns", so the next try never saw the validation error and repeated it (tb R1 ended run_failed at `MAX_SPEC_TRIES`). The checks also stopped at the first class that failed, and the evidence stage's spec problems came one stage later (tb R2). Now (`agents/stage_machine.py`): a try that ends without its completion output is checked on whatever draft is on disk, written in this try or left by an earlier one, and goes on if it validates; with no draft on disk, the earlier try's problems are kept, each marked once as "from an earlier try, still unresolved" (`_carry_feedback`; its cap trims carried items only). `Machine._spec_checks` runs every check class (derivations, cited inputs, derived inputs, pre-sign, geometry, and the evidence stage's spec problems through `_evidence_assess`, now shared with `h_EVIDENCE`) whatever the others found, and names a class that raises without dropping the others. Two guards stay: no check runs after a citation outside the run directory or a citation list that cannot be read (`_cites_outside`), and the evidence assessment, which builds the engine, runs only when the pre-sign checks and the signed-configuration guard pass (`_config_refused`). `agents/v2_sdk_tasks.py`: the spec draft gets its own turn cap, `SPEC_MAX_TURNS` = 60 (`SdkTasks.turns_for`). Other tasks keep 30, a caller's explicit `max_turns` holds for every task (the world-model seed's child session included), and the dollar allowance still bounds the call. The draft_spec prompt and the decision-spec skill state the two rules that cost retries in hb1: no digits in a decision test's text, and no `engine_parameters` value for a calibrated parameter (calibrate it) or a fitted one (leave it to the engine). Self-tests HS1-HS15 and HS13b (each failed before its change).
