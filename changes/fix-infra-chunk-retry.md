## Changelog

**v2: the autoscaler no longer retires a worker that is running a compute chunk; lost chunks are resubmitted within the call, and an analysis that failed only on infra rows can be resumed.** In the Nigeria v2 full run (F3, 2026-11-02), at the tail of a 256-point engine batch the keeper-held `adapt()` retired workers that were still running chunks. The two lost chunks were each resubmitted once, and both resubmissions were lost the same way. 16 rows came back `kind: infra`, the analysis failed closed, and the run ended `run_failed` with no way to resume. In `distributed==2026.8.0`, `Scheduler.workers_to_close(target=n)`, which Coiled's adapt calls, takes busy workers once it runs out of idle ones, and `retire_workers` does not wait for running tasks. Three changes. (1) `scripts/compute.py` `BusyWorkerGuard`: a scheduler plugin whose `valid_workers_downscaling` removes every worker with a task processing from the downscaler's candidates. It is registered by `register_compute_tags` (the launcher) and, idempotently, by every dask call, which records `busy_guard` in its summary. The keeper still holds `adapt()` client-side. (2) `scripts/compute.py` `_map_dask`: a lost chunk is resubmitted up to `MA_COMPUTE_INFRA_RETRIES` (default 2) times per input. Each lost attempt is charged, and its chunk entry records `losses`; the summary reports `resubmitted`. When no compute worker is taking work, the call waits up to `MA_COMPUTE_NO_WORKER_WAIT_S` (default 1,800 s) for the pool, then stops with infra rows. Model errors are not retried. (3) `agents/stage_machine.py` `analysis_failure_cause(rep, run_dir)`: returns the new cause `infra` when the failed step's engine batch failed only with kind infra. The cause is read from the `analysis/batch/*.summary.json` files that compute.py wrote during that pipeline run (`failed_by_kind`), not from the error text. `main.py --v2 --resume` then reopens the run at ANALYZE and recomputes only the failed rows. Rows computed by older code have another code fingerprint and are recomputed. Tests, written first: IR1-IR6 (`scripts/compute.py`, LocalCluster of 2 workers: busy workers are not picked to close, a worker retired under a chunk, bounded retries, model errors run once, the no-worker bound) and T61-T61c (`agents/stage_machine.py`).
