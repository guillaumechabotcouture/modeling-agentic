## Changelog

**A calibration refused under a signed spec gets a planned spec patch before the pause (hb3 triage fix 2b).** In hb3, flu R1's refusal went to SPEC, but under `--signoff lead` the request carried no patch, so the lead amendment was refused and the run paused. The #339 redraft branch runs only for unsigned specs (`--signoff none`, the one mode in which SIGN does not sign). It is kept for them, and its history line now reads "redraft n of 2". Under a signed spec, `h_ANALYZE` now asks the fix planner for one SPEC rethink on the `calibration_refused` finding. The planner gets one retry when the plan does not validate, and below the task floor it is skipped. The call is journaled under a key bound to the refusal and the signed spec, so a resume never replays a plan made for another refusal. `calibration_plan_problems` checks the plan: well-typed JSON, the planner's own plan checks, and amend.py's patch format. Applied in memory to the signed spec, the patch must change something, and only the calibration's `method`, `priors`, `parameters`, `range` or `scale`; targets, sources and their bindings stay as signed. The result is recorded in `calibration_patch_r<round>.json`, and the route is recorded in `run_state.json` `tries.calibration_patch`. `rethink_request` reads that plan only through this route, for the spec signed now. Under `--signoff lead` it is the request's `patch`, and `_lead_amend_locked` makes the provisional child. `toolkit/spec/amend.py` now defers the child's imported open review conditions to the owner (`review_conditions.lead_defer`, D2) under a lead amendment, as the lead does at SIGN, so the child dry-signs. Under owner sign-off it is `proposed_patch`, written to `spec_patch_proposed.json`. `amend --from-request --patch` reads that file as written, and the request's `next` lists the disposition and `amend --finish` steps. A fix-loop plan's SPEC patch is now proposed to the owner the same way. With no valid patch the run pauses as before. A child never copies `spec_patch_proposed.json` or `calibration_patch_*`; both are added to `harness_owned()`. Self-tests CRF5-CRF11.
