## Changelog

**Wider v2 uncertainty: published priors drawn in every draw, the DALY chain, scenario ranges, correlated emulator error, and a draw plan in the artifact (owner decision 2026-11-01).** A `prior` parameter has a published bounded range (uniform, loguniform or triangular with the point value as mode), a distribution and a citation, and is drawn in every uncertainty draw on its own random stream (`toolkit/spec/priors.py`; v2d note §2.4, §3.2). Engine-card priors live in `priors.yaml` beside the engine, which is card metadata: `toolkit/engines/malaria/engine.py` and `toolkit/engines/contract.py` are byte-identical, so the malaria code fingerprint and benchmark stamps are unchanged. The malaria file makes six parameters priors: net retention, use rate, SMC protective effectiveness, the two GBD 2019 disability weights, and the treated severe-malaria CFR (the AQUAMAT arms). It gives each other fixed parameter its reason (an assumption range with no source, a normative life table, no published range) and lists the module constants that need an engine change before they can be drawn. A fixed parameter left unaccounted for is refused. A spec may give a scenario or fixed parameter a published range in `uncertainty.priors`, and may fix a prior only with `uncertainty.excluded: {parameter, reason}`; `{kind: priors, reason}` fixes them all. Version-1 specs validate unchanged. Every drawn prior enters the emulator design over its declared range, and a design without one is refused, naming it. Each drawn prior also gets an automatic `prior_range` decision test, and one-way sensitivity covers it. The emulator error is now one joint draw per uncertainty draw: a common (population-mean) part and a per-unit part, both built from the held-out residual vectors, so it keeps the cross-package correlation and the error of an n-unit total no longer shrinks as 1/sqrt(n). The interval label names the prior-dominated parameters and what is held fixed. `uncertainty_report.yaml` and the uncertainty artifact carry the draw plan: every source drawn or not, every parameter drawn or fixed with why, and the error model's held-out evidence. Codex round 1 (three P1s, one P2) and round 2 (one P1, one P2) were fixed: likelihood calibration with drawn priors is refused, because its fit holds them at point values; the error model keeps the signed held-out mean, one column per population group, outcome and package; clamped calibration at a tested end is flagged; a scope that draws nothing is refused. Tests first: priors PR1–PR21, model ME1–ME5, run RP1–RP9, render_claims T1d, schema SP11b and SP17. Dry check: the hand-written Nigeria spec validates, and its plan lists all five sources.
