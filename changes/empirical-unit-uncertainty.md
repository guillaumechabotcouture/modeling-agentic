## Changelog

**Package-rate engine: per-unit rate uncertainty is drawn, and a degenerate headline interval is a finding.** hb3 triage fix 5 (tb_acf R1 and R2, malaria R1 D-001). In `trial_priors` mode the package-rate engine held each unit's measured baseline rates at their point values, so the uncertainty step drew only the effect priors (and, with `burden_anchor`, one common factor per unit over its outcomes added together): tb R1's interval was too narrow and tb R2's degenerate. Engine version 3 (`3-trial_priors-…`): an optional `baseline.sampling: {model: poisson, dispersion, outcomes, source}` adds the unit attribute `baseline_events` (the event count behind each unit's rate) and the method `draw_unit_attributes`, which draws each listed outcome's rate as rate x Gamma(n/phi, scale phi/n) (mean 1, CV sqrt(phi/n)); a zero count is refused. The card declares it, or says the rates are point values when it is absent. New conditional uncertainty source `unit_rates` (`toolkit/spec/schema.py`): drawn on its own stream, unit by unit, and passed to the engine through `DirectModel.unit_spec` for that evaluation only (`Analysis.evaluate(unit_attrs=)`); direct evaluation only, never fanned out. The schema refuses the source for an engine with no per-unit sampling or off direct evaluation (also before an engine is chosen), a declared sampling that is neither drawn nor excluded with a reason, and a unit without a positive count for a sampled outcome. Prefetched engine runs are refused with drawn unit values, and the figure step's own replay draws them too (Codex r1 P1-2, P1-3). In calibrated mode the per-unit log rates were already drawn jointly with the rate ratios from the panel fit's covariance (likelihood calibration), but the report counted only the ratios (`sampler_varied_parameters`), which is how malaria R1's critic read them as fixed; the report and `analysis/uncertainty.yaml` now carry `unit_values_drawn` (per route: calibration z, unit_rates) and `sampler_varied_unit_values`. `contract.interval_findings`: a headline fixed-plan interval narrower than `thresholds.yaml uncertainty.interval_rel_width_min` (1e-3) of its magnitude, or not numeric, is `analysis_interval_degenerate` (HIGH, not declarable); the headline is the signed spec's, which the artifact must name; an interval of exactly zero (a plan that averts nothing) is not a finding. The decision-spec skill documents both. Not addressed: measles R2's per-district serosurvey sampling (compartmental engine); value of information does not yet value the drawn unit rates as inputs (Codex r1 P2-7, open). Self-tests S1-S5, SE1-SE5, SE4b (engine), KI1-KI8 (contract), D4b (run).
