## Changelog

**Joint calibration by history matching, before the outcome batch (owner direction 2026-11-05: "we cant do calibration one variable at a time").** F5 failed at ANALYZE because the emulator inversion moved one transmission parameter per unit with every other parameter fixed: 57 of 309 units clamped at the top of the range, and the guard stopped the run about 1 h 45 min into the analysis. A new spec field `calibration.joint` (signed with the spec; without it nothing changes) calibrates shared parameters and the per-unit attribute together against every declared target, and returns the region of values compatible with all of them. Package choice: no maintained Python package covers this shape (mogp-emulator's HistoryMatching, last released 2022, fails on the current numpy; pyabc needs thousands of engine runs and has no emulator; emukit has no implausibility; calabaria and Starsim's calibration search for an Optuna point), so the step is ours, built on scipy and scikit-learn. Core `toolkit/calibration/history_matching.py` (no disease, place or intervention named; thresholds in `toolkit/calibration/thresholds.yaml`): waves of simulation; per-observable emulators (a regression mean over the unit parameter, the shared parameters and unit features plus a per-unit Gaussian-process residual with a unit random effect, hyperparameters shared across units; one Gaussian process per shared observable, optionally over its declared `depends_on` parameters); implausibility with emulator, sampling, source-bias and discrepancy variances (a target with no declared error is refused: no source is ground truth); profiling of the per-unit parameter; units no value in the prior box matches are reported with the direction of the miss and each target's modelled value, units matchable alone but not together as conflicting; a held-out emulator check per wave (5-fold cross-validation when the holdout is small) that fails closed; engine verification at the best point over each unit's interval; a region sample with an id. Adapter `toolkit/analysis/joint_calibration.py`: unit targets (one per unit per survey, sd from a value, a column, an interval or a sample size), group targets (a survey table at a coarser level, weighted over its units, sampling sd from its interval), benchmark targets (fit targets of the engine's own pack only: a held-out id is refused at validation, the PR #140 rule); simulations through the analysis batch (scripts/compute.py, so a Coiled cluster runs them), benchmark settings through the benchmark runner. ANALYZE (`toolkit/analysis/run.py`): the joint calibration runs before the outcome batch and an unmatched unit stops the run there (`analysis/blocked.yaml`, reason and units); the point plan uses the region's best shared values; the uncertainty draws take the shared values from the region sample (provenance checked like the posterior path); the automatic prior_range tests use the region's ends. Independently, an emulator inversion that clamps units now stops at the calibration step, before the point plan (F6 queue item; `blocking.clamped_units_max` 0). Tests, written first: HM1-HM10 (core), JA1-JA5 (adapter), JR1-JR5 (ANALYZE), AC1-AC3 (acceptance on the renewal engine with planted values: per-unit case, an unreachable unit, a canary with no units).
