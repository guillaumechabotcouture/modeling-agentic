## Changelog

**Joint calibration by history matching, before the outcome batch (owner direction 2026-11-05: "we cant do calibration one variable at a time").** F5 failed at ANALYZE because the emulator inversion moved one transmission parameter per unit with every other parameter fixed: 57 of 309 units clamped at the top of the range, and the guard stopped the run about 1 h 45 min into the analysis. A new spec field `calibration.joint` (signed with the spec; without it nothing changes) calibrates shared parameters and the per-unit attribute together against every declared target, and returns the region of values compatible with all of them. Package choice: no maintained Python package covers this shape (mogp-emulator's HistoryMatching, last released 2022, fails on the current numpy; pyabc needs thousands of engine runs and has no emulator; emukit has no implausibility; calabaria and Starsim's calibration search for an Optuna point), so the step is ours, built on scipy and scikit-learn. Core `toolkit/calibration/history_matching.py` (no disease, place or intervention named; thresholds in `toolkit/calibration/thresholds.yaml`): waves of simulation; per-observable emulators (a regression mean over the unit parameter, the shared parameters and unit features plus a per-unit Gaussian-process residual with a unit random effect, hyperparameters shared across units; one Gaussian process per shared observable, optionally over its declared `depends_on` parameters); implausibility with emulator, sampling, source-bias and discrepancy variances (a target with no declared error is refused: no source is ground truth); profiling of the per-unit parameter; units no value in the prior box matches are reported with the direction of the miss and each target's modelled value, units matchable alone but not together as conflicting; a held-out emulator check per wave (5-fold cross-validation when the holdout is small) that fails closed; engine verification at the best point over each unit's interval; a region sample with an id. Adapter `toolkit/analysis/joint_calibration.py`: unit targets (one per unit per survey, sd from a value, a column, an interval or a sample size), group targets (a survey table at a coarser level, weighted over its units, sampling sd from its interval), benchmark targets (fit targets of the engine's own pack only: a held-out id is refused at validation, the PR #140 rule); simulations through the analysis batch (scripts/compute.py, so a Coiled cluster runs them), benchmark settings through the benchmark runner. ANALYZE (`toolkit/analysis/run.py`): the joint calibration runs before the outcome batch and an unmatched unit stops the run there (`analysis/blocked.yaml`, reason and units); the point plan uses the region's best shared values; the uncertainty draws take the shared values from the region sample (provenance checked like the posterior path); the automatic prior_range tests use the region's ends. Independently, an emulator inversion that clamps units now stops at the calibration step, before the point plan (F6 queue item; `blocking.clamped_units_max` 0). Figures (owner request), `toolkit/calibration/figures.py`, drawn at the calibration step and listed in the figure manifest (data and model tier): a corner plot of the region ordered by co-variation, the most co-varying pairs with the prior box and point value, the optical depth by pair, every target's observed interval against the region's band, and the prior share per wave. The report also gives each shared parameter's region 95% interval against its prior's (`interval95`), because the extreme accepted values can span the prior while the region's mass moves. Codex review, two rounds, every P1 fixed test-first (round 1: group targets profiled jointly, ANALYZE uses the joint unit values, validation never splits repeated inputs; round 2: overlapping group targets as one component, a failed wave check is not erased by a later pass, every varied parameter shared or declared independent). Real smoke on the Nigeria inputs (Coiled, 309 units, 2 waves, unit targets for one survey year, state targets for another, five fit-joint benchmarks; counts in the PR, values local only). Tests, written first: HM1-HM16 (core), JA1-JA6 (adapter), JR1-JR7 (ANALYZE), AC1-AC3 (acceptance on the renewal engine with planted values: a per-unit case with a shared trial target, an unreachable unit, a canary with no units), CF1-CF4 (figures).
