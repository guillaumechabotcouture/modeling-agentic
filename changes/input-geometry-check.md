## Changelog

**A standing check of the units' coordinates and areas against boundaries (design note `docs/design/v2-input-geometry.md`).** In a real run, the geography input table had been built from a boundary set in which 4 pairs of unit names were attached to each other's polygons, so each unit in a pair carried its partner's coordinates, area and population, and nothing in the harness caught it. `toolkit/spec/geometry.py` checks the spec's units table against the boundaries declared in the run's unsigned presentation file (the figures' `boundaries: {path, feature_id, crosswalk, credit}` block; columns from `decision_units.coordinates: {lat, lon, area_km2}` or named lat/lon/area_km2). It uses pure Python and json: ray casting with holes and MultiPolygon parts, and planar areas and distances with a cos-latitude scale. Codes: `reciprocal_swap` (HIGH), `point_outside_own_polygon` (HIGH beyond `edge_tolerance_km`, LOW edge case within it), `area_mismatch` (MEDIUM beyond `area_ratio_max`, HIGH when the area matches the polygon the point falls in), `unmatched` (MEDIUM unit without a polygon, HIGH polygon claimed twice), `geometry_check_failed` (HIGH, fail closed on malformed inputs) and `geometry_check_not_run` (LOW: never a silent pass). Thresholds (5 km, 1.5) are in `effort_floors.yaml` `input_checks.geometry`, not in `toolkit/analysis/thresholds.yaml`, which is hashed into every benchmark declaration digest. The harness writes `data/input_checks.json` (harness-owned). `h_SPEC` refuses a spec with an unaccepted HIGH, and the gate re-runs the check through `harness_findings`. The sign-off sheet lists the counts, each acceptance and the open findings. A HIGH is cleared by fixing the data or by accepting it by name in the signed spec, `decision_units.geometry_accepted: {<finding id>: reason}` (the `defaults_accepted` pattern); a stale or reasonless acceptance is `geometry_acceptance_invalid`. Tests were written first: IG1-IG7 (`toolkit/spec/geometry.py`), IG-M1-M3 (`agents/stage_machine.py`) and IG-S1 (`toolkit/spec/signoff.py`). A local check against the real run's files found the 4 pairs (counts only in the PR).
