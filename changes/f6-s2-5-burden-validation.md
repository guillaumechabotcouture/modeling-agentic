## Changelog

**Absolute burden checked against external estimates (F6 S2-5, critique C7).** A spec may declare `validation.burden` (`csv`, `group`, `arm`, `daly_parts`): a reference file, under a contract checked by `toolkit/spec/schema.py` before sign-off, that lists external estimates of outcomes the engine reports. Each row gives the group (a value of the group column, or `*` for every unit), an optional age band (a `decision_units.populations` group), the outcome, count or rate per N people, the year, the value and its interval, the source, the kind (`estimated`, or `reported`, which is shown for information only and never judged) and a tolerance (a ratio band, by default and at most as wide as `toolkit/analysis/thresholds.yaml` `burden` allows, or interval overlap). The reference file is refused when it is any calibration input (`calibration.targets.csv`, every `calibration.joint.targets[*].csv`, or the units table that holds the inversion and joint unit targets), compared by real path, inode and content hash, so aliases and copies are caught; a reference whose value repeats a fitted observation in a row naming its group is refused too. The artifact records this provenance. Blank ratio-band cells take the manifest default; unparsable or non-finite ones are refused. The analysis (`toolkit/analysis/burden.py`) compares the continuation arm (the comparator, or the declared `arm`) with each reference, as the arm's annual mean over the decision window. It reports the ratio, the reference interval as ratios and the model interval: from the uncertainty draws for all-age references, or the point value with a statement for an age band. Results go in the new optional artifact `analysis/burden_validation.yaml`, with the share of the arm's DALYs that comes from deaths (when years of life lost per death are declared) and the plan's DALYs averted per death averted. Model corrections on the validation arm stop the analysis, at the point, in every uncertainty draw (precomputed draws included) and in the age-band predictions. The contract check (`toolkit/analysis/contract.py`) reads the declared references again from the signed spec, requires each exactly once with its declared metadata and at least one estimated row, and re-judges every row from its numbers (a reported row needs a model value before it is shown for information). An estimated reference outside its tolerance is a declarable HIGH finding (`burden_outside_tolerance`). A declared check with no artifact, an unmatched reference, or a status or band that the numbers or the manifest do not support is a HIGH finding that cannot be declared. `results.md` gains a section, the claims ledger a claim per number, and the figure set a `burden_validation` diagnostic (model / reference on a log axis, with both intervals). Self-tests: `burden.py` BV1–BV21, `run.py` BE1–BE6. No reference values are in the repository; the Nigeria reference file is built separately.
