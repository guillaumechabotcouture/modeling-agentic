## Changelog

**Absolute burden checked against external estimates (F6 S2-5, critique C7).** A spec may declare `validation.burden` (`csv`, `group`, `arm`, `daly_parts`): a reference file, under a contract checked by `toolkit/spec/schema.py` before sign-off, that lists external estimates of outcomes the engine reports. Each row gives the group (a value of the group column, or `*` for every unit), an optional age band (a `decision_units.populations` group), the outcome, count or rate per N people, the year, the value and its interval, the source, the kind (`estimated`, or `reported`, which is shown for information only and never judged) and a tolerance (a ratio band, by default and at most as wide as `toolkit/analysis/thresholds.yaml` `burden` allows, or interval overlap). The reference file is refused when it is any calibration input (`calibration.targets.csv`, every `calibration.joint.targets[*].csv`, or the units table that holds the inversion and joint unit targets), compared by real path, inode and content hash, so aliases and copies are caught. Independence from the calibration's data is declared, not inferred: each reference row names its `source_id` (the publication or dataset) and `derived_from` (upstream source ids); every calibration input names its source ids (observation targets per row, `calibration.targets.source_id`, `calibration.target_source_id` for the inversion target column, `source_id` on each joint unit or group target); a reference whose source or upstream source is a calibration source is refused. The artifact records the declared provenance and the sign-off sheet shows it, so the owner attests independence. Signing binds the reference file's bytes as it binds the derivation record (`toolkit/spec/signoff.py`): its full sha256 is in the sheet's machine-readable sources and in the sign-off record (both the spec-only and the decision-brief paths); a sheet generated from other bytes is refused at signing as stale, a file changed or removed after signing makes the spec's status `changed`, and the contract check reports a run whose reference file no longer matches its sign-off as a finding that cannot be declared. The reference path is never normalised: validation, the sheet, signing, status and the analysis read the file through one no-follow helper (`burden.read_reference`), which refuses an absolute path, a `.` or `..` component and a link anywhere; the sheet and signing each read it once and render, validate and hash those same bytes. Blank ratio-band cells take the manifest default; unparsable or non-finite ones are refused. The analysis (`toolkit/analysis/burden.py`) compares the continuation arm (the comparator, or the declared `arm`) with each reference, as the arm's annual mean over the decision window. It reports the ratio, the reference interval as ratios and the model interval: from the uncertainty draws for all-age references, or the point value with a statement for an age band. Results go in the new optional artifact `analysis/burden_validation.yaml`, with the share of the arm's DALYs that comes from deaths (when years of life lost per death are declared) and the plan's DALYs averted per death averted. Model corrections on the validation arm stop the analysis, at the point, in every uncertainty draw (precomputed draws included) and in the age-band predictions. The contract check (`toolkit/analysis/contract.py`) reads the declared references again from the signed spec, requires each exactly once with its declared metadata and at least one estimated row, and re-judges every row from its numbers (a reported row needs a model value before it is shown for information). An estimated reference outside its tolerance is a declarable HIGH finding (`burden_outside_tolerance`). A declared check with no artifact, an unmatched reference, or a status or band that the numbers or the manifest do not support is a HIGH finding that cannot be declared. `results.md` gains a section, the claims ledger a claim per number, and the figure set a `burden_validation` diagnostic (model / reference on a log axis, with both intervals). Self-tests: `burden.py` BV1–BV27, `run.py` BE1–BE7. No reference values are in the repository; the Nigeria reference file is built separately.
