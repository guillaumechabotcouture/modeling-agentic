## Changelog

**Absolute burden can be anchored to external estimates while the engine's relative reductions are kept (owner, 2026-11-12, design principle 3).** Until now every outcome came from the engine or emulator, and the burden check (`validation.burden`) only compared the continuation arm with external references. A reference row may now have role `anchor` (and an optional `group_by` column, blank = `validation.burden.group`): an estimated, all-ages row (count or rate) for an outcome the spec reports, which needs `validation.burden.window`. Its factor is the external value divided by the arm's value over the model window for its group (the window's `burden` outputs, never the decision horizon), with an interval of lower/model to upper/model. `Analysis.anchor` multiplies every package's anchored outcome in the group's units by that factor, and the window burden too (by population group as well). Reductions relative to the comparator are unchanged; absolute burden, and so outcomes averted, move to the external level. `run.py` computes the factors from the first point evaluation (the arm guarded for model corrections), re-evaluates before the plan is solved, and writes `analysis/burden_anchor.yaml` (each row's model value, external value, factor, interval, group column, unit count, and whether it shares a source with the calibration). The point plan, uncertainty draws, stability, sensitivity, decision tests, variants and the burden validation all see anchored outcomes because they call `A.evaluate`. In a draw that carries the emulator error, each anchor's factor is drawn log-uniformly within its interval from the same generator; the point uses the point factor. A reported DALY outcome that is not anchored itself, built from anchored deaths or cases, follows `daly_parts` (new optional `cases` key): YLL = deaths x `yll_per_death.all`, YLD = DALYs - YLL (floored at 0), anchored DALYs = f_deaths x YLL + f_cases x YLD. The analysis stops if `daly_parts` cannot say how. Fail closed: a model value of 0 or below; a factor or interval end outside `thresholds.yaml burden_anchor` [0.05, 20]; a unit covered by no anchor row, or by more than one, for an anchored outcome; an anchor with an age band, without a model window, of kind reported, or with a `group_by` that is not a units column. Anchors are exempt from the independence refusal: they set a level and validate nothing, and the artifact records the overlap. They are never judged. A section with anchors and no checked row is accepted, and still refused if it has neither. The gate adds `burden_anchor_missing` and `burden_anchor_inconsistent` (not declarable). results.md and the claims show each factor, and the sign-off sheet marks anchor rows with their group column. Self-tests BA1-BA6 (burden.py) and the end-to-end BA3/BA6 run (run.py `_self_test_anchor_e2e`) were written first and failed before the change. No cloud run.
