## Changelog

**Absolute burden can be anchored to external estimates while the engine's relative reductions are kept (owner, 2026-11-12, design principle 3).** Until now every outcome came from the engine or emulator, and the burden check (`validation.burden`) only compared the continuation arm with external references. A reference row may now have role `anchor`, with an optional `group_by` column (blank = `validation.burden.group`). An anchor is an estimated, all-ages row (count or rate) for an outcome the spec reports, and it needs `validation.burden.window`. In every evaluation (point, uncertainty draws, stability folds, sensitivity, decision tests, variants, rebuilds), `Analysis.anchor` multiplies every package's anchored outcome in the group's units by the external value over that evaluation's own arm value over the model window for the group. A partial evaluation (a stability fold) is widened to whole anchor groups, so the merged result keeps each group's anchored total. The emulator boundary check evaluates both sides at the decision's point factors. The anchored absolute burden is therefore the external level in every evaluation, and only the reductions relative to the comparator come from the engine. The factor also applies to the grouped outcomes (`y_group`), the window burden (by population group too) and the cost outputs listed in `validation.burden.cost_scaling: {cost output: anchored outcome}`. Unlisted cost outputs are declared not burden-driven, and the sign-off sheet shows both lists. `run.py` computes the point factors from the first point evaluation (the arm checked for model corrections), re-evaluates before the plan is solved, and writes `analysis/burden_anchor.yaml`. It records each row's model value, external value, factor, interval, group column and unit count, whether the row shares a source with the calibration, each row's scale, the cost scaling and the DALY composition. `figure_data.rebuild()` restores the anchor from that artifact. A new uncertainty source `burden_anchor` must be declared, or excluded with a reason, whenever an anchor has an interval. It draws each external value from a lognormal whose central 95% is the published [lower, upper], from its own seeded stream, on either evaluation path. A reported DALY outcome that is not anchored itself, built from anchored deaths or cases, follows `daly_parts` (new optional `cases` key): YLL = deaths x `yll_per_death.all` (a parameter is read at the evaluation's values), YLD = DALYs - YLL, anchored DALYs = f_deaths x YLL + f_cases x YLD. A negative YLD stops the analysis, with the numbers. The spec is refused:
- when `daly_parts` cannot say how DALYs are composed;
- when DALYs are in the model window without deaths;
- when an anchor has an age band, has no model window, is of kind reported, has a `group_by` that is not a units column, or has a published lower bound of 0;
- when `cost_scaling` names an unknown cost output or an outcome no anchor sets;
- when any other row shares an anchor's source.

The analysis fails closed when a model value is 0 or below, when a point factor or interval end falls outside `thresholds.yaml burden_anchor` [0.05, 20], or when a unit is covered by no anchor row, or by more than one, for an anchored outcome. Anchors are never judged. They are exempt from the independence refusal (they set a level and validate nothing), and the artifact records the overlap. A section with anchors and no checked row is accepted, and is still refused if it has neither. The gate adds `burden_anchor_missing` and `burden_anchor_inconsistent` (not declarable). It reconciles each row, the arm, the window, unit coverage, cost scaling and the DALY composition with the signed spec, and checks the factor bounds on both interval ends. Each anchor's published interval is a sensitivity (tornado) row and an automatic decision test (`anchor_range_<id>`). DALYs anchored directly beside reported deaths must keep YLD = DALYs - deaths x yll_per_death >= 0 in every evaluation (the outcomes of one group are drawn with one shared normal per draw), or the analysis stops with the numbers. The gate and `restore_anchor()` check each stored scale against the signed window and populations, and that every unit is covered exactly once. results.md and the claims show each factor. Self-tests BA1-BA14 (burden.py) and run.py `_self_test_anchor_e2e` were written first and failed before each change (review rounds 1 and 2 included). No cloud run.
